# Тестирование

Всего **169 автоматических тестов**: 155 на JVM (domain 78, data 48, app 29) и 14 instrumented на эмуляторе. Ни один не обращается к реальному GPS, тайловым серверам или облаку. Координаты в тестах синтетические.

## Команды

```bash
./gradlew test                          # все JVM-тесты: unit + интеграционные (Robolectric)
./gradlew :domain:test                  # бизнес-логика и гео-алгоритмы, чистый JVM
./gradlew :data:testDebugUnitTest       # интеграционные: Room in-memory, backup, sync, MockWebServer
./gradlew :app:testDebugUnitTest        # ViewModel'и, GeoJSON-адаптер
./gradlew connectedDebugAndroidTest     # instrumented — нужен эмулятор/телефон (adb devices)
./gradlew lintDebug                     # Android Lint
```

Отчёты: `*/build/reports/tests/…/index.html`, `app/build/reports/androidTests/connected/debug/index.html`.

> Robolectric при первом запуске скачивает `android-all` для SDK 35 из Maven Central (`data/src/test/resources/robolectric.properties`). Нужна сеть или прогретый кэш `~/.m2`.
> `connectedDebugAndroidTest` после прогона удаляет приложение вместе с данными.

## Ручная проверка на эмуляторе (выполнена при разработке)

Синтетические координаты подавались через `adb emu geo fix`:
- onboarding, выдача разрешений, карта OpenFreeMap загружается;
- Fog of War: полоса вдоль маршрута открывается, остальное закрыто облаками; Explorer Map: вся карта и подсветка с контуром;
- серия скриншотов при старте и во время записи: **ни одного кадра с подложкой вне исследованного** (после исправления двойной буферизацией);
- запись при выключенном экране и свёрнутом приложении: +12 точек за 45 с в состоянии `Asleep`, сервис `isForeground=true`;
- кнопка «Остановить» в уведомлении закрывает трек (`COMPLETED`) и сервис;
- после убийства процесса (переустановка) запись продолжилась, показано сообщение;
- история и детальный экран с треком, маркерами и статистикой GPS.

## Не покрыто автоматически (требует реального устройства/аккаунта)

- Реальный GPS на улице, поведение Doze и оболочек производителей.
- Настоящий проект Supabase (см. SYNC.md). SQL-схема проверяется вручную: `python supabase/verify_schema.py supabase/schema.sql "<conninfo>"` против одноразового PostgreSQL 15+ (скрипт пересоздаёт схемы `public` и `auth`).
- Диалоги Storage Access Framework (выбор файла): логика экспорта/импорта покрыта тестами с файловыми путями.
- Миграции Room: пока одна версия схемы. При появлении v2 добавьте тест на `MigrationTestHelper`.
