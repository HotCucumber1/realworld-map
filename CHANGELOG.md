# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.1.0] — 2026-10-24

Первый MVP.

### Добавлено
- Карта MapLibre Native 13.7.1 со стилями OpenFreeMap (Liberty/Positron/Bright), растровым OSM и пользовательским стилем по URL.
- Режимы **Fog of War** (непрозрачная маска «облака» или «тёмный слой», мягкие края) и **Explorer Map** (подсветка и контур). Переключение не меняет данные.
- Исследованная территория на глобальной сетке 1/20000°: радиус 10/20/30/50/100 м, сводные уровни для мелкого масштаба, трассировка контуров, сглаживание, учёт антимеридиана.
- Двойная буферизация маски тумана: во время обновлений неисследованная карта не мелькает.
- Запись маршрута в foreground service (`location`): уведомление с кнопкой «Остановить», адаптивный интервал, сторожевой таймер сигнала, восстановление после гибели процесса.
- Фильтр GPS: координаты, время, точность (≤40 м), дубликаты, всплески, скачки (>85 м/с), релокация.
- Room (схема v1, экспорт схемы, транзакционная запись точки и территории), DataStore для настроек.
- История маршрутов и детальный экран: трек на карте, длительность, расстояние (haversine), качество GPS.
- Экспорт/импорт: ZIP + JSON Lines, формат v1, SHA-256, лимиты размера, двухфазная проверка, транзакционное применение, режимы «Объединить»/«Заменить» с safety-копией.
- Облачная синхронизация через Supabase: e-mail-аутентификация, RLS, инкрементальный push/pull по `seq`, LWW для треков, множество ячеек с минимальным `first_visited_at`, WorkManager, удаление облачных данных и аккаунта, токены в Android Keystore. SQL-схема `supabase/schema.sql` и скрипт проверки.
- Onboarding, экраны настроек, backup и облака; тема Material 3 (светлая/тёмная).
- 155 JVM-тестов и 14 instrumented-тестов; документация README, ARCHITECTURE, TESTING, BACKUP_FORMAT, SYNC.

### Известные ограничения
- Синхронизация с настоящим проектом Supabase не проверялась (нет credentials в среде разработки).
- Нельзя удалить отдельный маршрут.
- Смена радиуса не пересчитывает уже открытую территорию.
