# Формат резервной копии World Explorer

**Идентификатор:** `world-explorer-backup` · **Версия формата:** `1` · **Версия схемы БД:** `1`

Резервная копия — обычный ZIP-архив (`.zip`). Записывает его `data/backup/BackupWriter.kt`, проверяет `BackupReader.kt`, применяет `BackupImporter.kt`.

## Состав архива

| Файл | Формат | Содержимое |
|---|---|---|
| `settings.json` | JSON-объект | переносимые настройки |
| `tracks.jsonl` | JSON Lines | один маршрут на строку |
| `points.jsonl` | JSON Lines | одна GPS-точка на строку |
| `cells.jsonl` | JSON Lines | одна исследованная ячейка на строку |
| `manifest.json` | JSON-объект | версии, счётчики, SHA-256 остальных файлов. Пишется последним |

Других файлов быть не должно: архив с лишним файлом отклоняется. Кодировка UTF-8, строки разделяются `\n`, последняя строка тоже им заканчивается. JSON Lines выбран, чтобы экспорт и импорт шли потоково, запись за записью, и не загружали миллионы точек в память.

Время везде — **миллисекунды Unix epoch в UTC**. Координаты — WGS84, градусы.

### `manifest.json`
```json
{
  "format": "world-explorer-backup",
  "formatVersion": 1,
  "schemaVersion": 1,
  "appVersion": "0.1.0",
  "createdAtUtc": 1761312000000,
  "trackCount": 12,
  "pointCount": 18450,
  "cellCount": 402113,
  "entries": {
    "settings.json": { "sha256": "…", "bytes": 214, "lines": 0 },
    "tracks.jsonl":  { "sha256": "…", "bytes": 3120, "lines": 12 },
    "points.jsonl":  { "sha256": "…", "bytes": 3870021, "lines": 18450 },
    "cells.jsonl":   { "sha256": "…", "bytes": 21001221, "lines": 402113 }
  }
}
```

### `tracks.jsonl`
```json
{"id":"6f0c…","startedAtUtc":1761300000000,"endedAtUtc":1761303600000,"status":"COMPLETED","distanceMeters":4210.5,"pointCount":901,"rejectedPointCount":37,"lastPointAtUtc":1761303598000,"createdAtUtc":1761300000000,"updatedAtUtc":1761303600000}
```
`status`: `ACTIVE` | `COMPLETED` | `INTERRUPTED`. `endedAtUtc` и `lastPointAtUtc` могут отсутствовать.

### `points.jsonl`
```json
{"id":"a1b2…","trackId":"6f0c…","latitude":48.1371,"longitude":11.5754,"timestampUtc":1761300004000,"accuracyMeters":4.8,"altitudeMeters":521.0,"speedMetersPerSecond":1.4,"bearingDegrees":87.0,"source":"FUSED","exploreRadiusMeters":20}
```
`altitudeMeters`, `speedMetersPerSecond`, `bearingDegrees` необязательны. `source`: `GPS` | `FUSED` | `NETWORK` | `PASSIVE` | `UNKNOWN` (незнакомое значение читается как `UNKNOWN`). `exploreRadiusMeters` — радиус, которым точка открыла территорию. По нему территорию можно восстановить детерминированно.

### `cells.jsonl`
```json
{"row":2762742,"col":3831508,"firstVisitedAtUtc":1761300004000}
```
Ячейка глобальной сетки с шагом 1/20000°: `row = floor((lat + 90) · 20000)`, `col = floor((lon + 180) · 20000)`; диапазоны `[0, 3 600 000)` и `[0, 7 200 000)`. Производные таблицы (грубые уровни, статистика площади) в архив не входят: при импорте они пересчитываются.

### `settings.json`
```json
{"mapMode":"FOG_OF_WAR","exploreRadiusMeters":20,"trackingProfile":"BALANCED","showTrack":true,"showExploredHighlight":true,"fogStyle":"CLOUDS","mapStyle":"OPENFREEMAP_LIBERTY","customStyleUrl":""}
```
Аккаунт, токены, состояние синхронизации и onboarding **не** экспортируются.

## Проверки при импорте

Импорт идёт в две фазы. Сначала файл копируется во внутренний кэш (лимит **1 ГиБ**) и **полностью проверяется**. Изменений в данных на этом этапе нет:

1. Это корректный ZIP; в нём только разрешённые имена, без дубликатов.
2. `manifest.json` ≤1 МиБ, `format` совпадает, `formatVersion` в диапазоне `1..1`. Иначе ошибка «версия не поддерживается».
3. Для каждого файла: распакованный размер ≤4 ГиБ (защита от zip-бомб), строка ≤64 КиБ, SHA-256, размер и число строк совпадают с манифестом, файл не обрезан.
4. Каждая запись: обязательные поля и типы; id — `[A-Za-z0-9_-]{1,64}`; координаты в допустимых диапазонах; время > 0; `endedAt ≥ startedAt`; точность ≥ 0 и конечна; радиус 1..1000; ячейки в пределах сетки; радиус в настройках из списка 10/20/30/50/100.
5. Уникальность id маршрутов; каждая точка ссылается на маршрут из этого же архива.
6. Число записей совпадает с манифестом.

Затем изменения применяются **в одной транзакции Room**. При любой ошибке всё откатывается, частичного импорта не бывает.

## Правила слияния

| Ситуация | Поведение |
|---|---|
| Маршрут с новым id | добавляется |
| Маршрут с совпадающим id | остаётся версия с бо́льшим `updatedAtUtc`; при равенстве — локальная. Локальный маршрут, который сейчас записывается, не перезаписывается |
| Точка с совпадающим id | точки неизменяемы: дубликат игнорируется |
| Ячейка уже исследована | остаётся, `firstVisitedAt` = минимум из двух |
| Маршрут в архиве `ACTIVE` | импортируется как `INTERRUPTED` (`endedAt` = последняя точка): на этом телефоне он не записывается |
| Статистика маршрута | после слияния пересчитывается по фактическим точкам (haversine) |
| Настройки | в режиме «Объединить» не меняются, в режиме «Заменить» берутся из архива |

**Режим «Заменить»:** перед ним текущие данные (если они есть) экспортируются в `files/backups/before-replace-<время>.zip` во внутренней памяти; хранятся 3 последних копии. Затем в той же транзакции удаляются маршруты, точки и территория, вставляются данные архива и сбрасываются курсоры синхронизации (следующая синхронизация объединит результат с облаком).

Повторный импорт того же файла в режиме «Объединить» ничего не меняет: тест `repeated merge import is idempotent`.

## Совместимость

- Читатель игнорирует неизвестные поля (`ignoreUnknownKeys`). Добавлять **необязательные** поля можно без смены версии формата.
- Удаление и переименование поля, изменение смысла или единиц требуют `FORMAT_VERSION + 1` и поддержки чтения старой версии в `BackupReader`.
- Новая версия приложения обязана читать все предыдущие версии формата. Старая версия честно отказывается читать более новую.
